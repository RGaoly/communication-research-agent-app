# 研究工作台：使用、部署与能力边界

版本：0.2.0a5.dev5，开发预览。此页面接入真实研究引擎，不包含预设研究结果。

**已上线地址：** https://communication-research-agent-rgaoly.streamlit.app/

**当前云端实测限制：** Community Cloud页面、项目保存和材料工作区可用，但真实隔离自检失败；该实例的替代文件隔离接口返回`ENOSYS`。自动研究执行保持禁用，不能把网页上线称为云端研究闭环已通过。首页会在上传前显示实际能力检查结果。完整统计可在经验证的本机环境运行；独立云端执行服务器需另行配置并验收。

## 你可以完成什么

通过浏览器建立项目，接入CSV/Stata DTA与有权使用的文献，核查题项和编码，保存并冻结研究计划，在授权范围内执行统计与模型任务，查看实际结果和证据，编辑写作材料，复核后下载成果。没有模型也可以执行本地统计和证据校验，但需要自行提供计划和写作材料。

项目内确认只代表填写者的研究决定，不是身份认证、伦理审查或独立专家验收。尚未完成的真实模型保留集、文献双专家核查、独立真人验收和三个真实项目，不能由软件测试替代。本版本不得宣称已通过正式自主科研系统验收。

## 从空项目到研究成果

1. **建立研究**：填写真实问题、研究名称和预期交付。仅模拟练习时勾选模拟项目；模拟结果不能计为真实研究。
2. **材料与测量**：云端用户先同意上传与处理，再选择文件。CSV须为UTF-8、有唯一表头；DTA保留原始数值，不自动把值标签变成响应值。原件保存在项目内，分析使用新的副本。
3. **核查编码**：对照问卷修正题项含义、量尺和类型。观测范围不是问卷量尺。排除姓名等身份字段；将明确的拒答/不知道编码映射为缺失。高级代码本可声明反向题、量表、分组和权重。填写实际核查人和依据再保存，不静默删除样本。
4. **文献与证据**：上传授权材料，定位实际页码或段落，填写题录、原文片段、所支持/反驳的论断和核查依据。原文精确定位通过不等于语义支持已被程序证明。仅有DOI、题录或摘要不能被描述为读过全文。
5. **模型与设置**：可保持离线；若使用模型，请从厂商控制台确认固定模型ID、端点、费率和预算。保存配置后填写本会话密钥，密钥不写入项目文件、恢复包或共享环境变量。填写实际查阅的官方规范来源和日期。
6. **项目授权**：研究概览中审阅问题、权限、模型和累计预算。填写实际审阅者、判断和版本确认短语。不提供通用“全部同意”按钮。
7. **形成计划**：可先手动在研究计划填写理论、竞争解释、已核查证据、实际变量和主模型；也可在模型契约通过后，让引擎基于已核查材料提出计划。连接契约需要两次付费请求，属于项目授权预算，不代表科研盲测通过。
8. **执行并冻结**：点击继续执行，系统先审计与核查证据，完成计划后等待冻结。核对全部规格、排除与缺失规则、此前看过的结果，明确确认。未经冻结不执行主分析。
9. **分析与写作**：继续执行后，查看实际模型N、参数、置信区间、拟合和诊断。无模型时自行填写四部分写作材料；用 `{{claim:实际ID}}` 引入统计量、`[[cite:实际文献ID]]` 引用文献。保存后继续运行以生成稿件和复核。
10. **交付**：阻断项解决后可终审。未终审只能导出明确标记的工作稿。可以另行确认包含分析数据，也可导出诊断包。DOCX目前使用内部引文键，完整期刊排版与匿名元数据仍须实际检查。

各页面的数字来自后台文件、执行记录或账本。没有结果显示尚未生成；输入变化的旧结果显示为过期。后台任务结束不等于研究完成，只有当前证据齐全并完成终审才显示完成。

## 数据与运行边界

- 云端模式下，选择并确认上传的文件会进入Streamlit托管服务器，不能再称为“原始数据仅在本机”。系统不会自动读取或上传开发者/用户电脑上的其他文件。
- 模型只接收通过研究引擎检查的结构摘要、聚合结果与明确允许外传的文献片段；统计进程无网络，不能获得密钥或批准状态写权限。
- 云端每个浏览器会话使用独立的随机工作区；本机模式使用当前操作系统用户的持久研究库，重新打开浏览器后仍能选择已有项目。密钥在两种模式下都按浏览器会话隔离，不会随研究库共享；页面不接受任意服务器文件路径，不会自动采用服务器共享模型密钥。
- 密钥在会话内存中按项目配置绑定，按授权时长到期。配置变化、手动清除或成果终审会使其失效。运行中清除密钥会请求暂停，但已经发出的外部请求不能保证取消。
- 页面代码升级时先安全停止旧会话任务，再接管同一研究库；不继承旧密钥或未提交的确认窗口。研究文件和已记录的真实决定保留，证据版本变化仍按依赖失效，不能自动代签新版本。
- Community Cloud空间可能重启、休眠或回收；当前不承诺跨服务器重启自动恢复。请在稿件与交付下载私有恢复备份，回到首页重新导入。备份包含原始材料与状态，需保存到受控位置；不含会话密钥。恢复后授权需重新确认。
- 单份数据32MB，最多250,000行、500列、5,000,000单元格；单份文献20MB。容量检查不是数据质量证明。
- 目前支持关联推断下的OLS、Logit、明确逆方差权重的WLS及已支持的标准误。SEM、完整复杂抽样、多层模型、未经核查的跨国潜变量均值比较不能仅凭提示词启用。
- 未设置模型权限、正数费率与预算，不发起付费模型任务。账本按配置费率估算，可能与缓存折扣、峰谷价格和厂商账单不同；建议填写最高适用费率。
- 结果或费用不明的请求保留为待核对，不自动重发。请依据厂商账单核对，不能为了继续运行任意填零。
- 本工具没有自动对外投稿、发布论文或招募真人的能力。上传材料、模型调用与成果导出权限相互区分。

## 本机启动

macOS可双击仓库中的 `启动研究工作台.command`。已有完整Python 3.12环境时直接打开本机工作台；首次缺少依赖时，只有实际输入 `INSTALL` 后才下载声明的依赖到项目专用 `.cra-runtime`，不会覆盖系统Python或已有 `.venv`。模型密钥始终在页面填写。启动器仅监听本机回环地址，关闭终端会结束服务。

使用Python 3.12；在仓库目录执行：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install '.[engine,ui]'
CRA_DEPLOYMENT=local .venv/bin/python -m streamlit run streamlit_app.py
```

本机模式的材料默认保存在启动目录的 `.cra-workspaces/本机用户研究库/项目ID`，可以用 `CRA_WORKSPACE_ROOT` 指定专用受控目录。同一操作系统用户重新打开后可选择已有项目；不同浏览器会话不共享模型密钥。旧版本随机会话工作区仍可通过其恢复备份导入，不静默迁移或覆盖旧项目。云端仍使用临时目录与随机会话，必须依靠私有恢复备份跨回收恢复。依赖安装是明确的部署步骤，引擎不自动安装或升级统计方法。

## Streamlit Community Cloud部署

应用入口：仓库根目录 `streamlit_app.py`。Python选择3.12。`requirements.txt` 安装本项目engine/ui依赖，`packages.txt` 请求安装bubblewrap，`.streamlit/config.toml` 配置主题、上传容量和跨站请求防护；默认关闭Streamlit使用统计。

使用目标GitHub仓库及已验收提交部署，不上传原始研究数据、私有文献、密钥、工作目录和本机路径。默认模式为cloud，不需要设置共享 `CRA_API_KEY`。用户在每次自己的会话中填写密钥。

**安装bubblewrap不证明托管内核允许隔离执行。** 部署后必须实际执行隔离自检与模拟闭环。若云端内核禁止用户命名空间或缺少必要隔离能力，统计执行会停止，不会回落为无隔离运行。此时页面仍能接入/整理材料，但不能宣称云端研究闭环通过，需调整托管执行环境或引入另行验收的工作进程。

发布前还应核查应用访问范围、数据保留安排、真实资源上限与用户支持渠道。开发预览不能作为多人生产环境的安全认证；随机会话隔离也不是完整组织身份与访问管理。

官方部署与依赖说明：

- [Community Cloud部署](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app)
- [Python与系统依赖](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/app-dependencies)

## 工程验收入口

```sh
python -m pip install '.[engine,ui,acceptance,test]'
CRA_ISOLATION_TESTS=1 python -m pytest -q
```

工作台测试位于 `tests/workspace/`，包括会话隔离、上传同意、原件保留、DTA标签、编码核查、确认版本绑定、密钥过期与共享密钥拒绝、恢复备份、恶意路径、事件并发、真实OS统计与导出，以及原生表单。所有测试审阅记录均明确标记为合成工程夹具，不得代替真人研究验收。
