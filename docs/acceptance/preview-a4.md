# v0.2.0a4 Alpha 开发预览

本次按研究者“先上线”的指示发布开发预览。正式科研系统的验收门槛不变，`release_eligible` 仍应为 false。预览发布不是独立专家验收、科研正确性认证或允许自动对外投稿。

## 使用入口

从 GitHub Release 下载 wheel，在预先审核的 Python 环境安装 `[engine]` 依赖后运行 `cra-gui`，即可在本地页面填写模型密钥。下载源码的 macOS 用户也可双击仓库根目录的 `启动模型配置.command`。密钥无需写入 CLI 环境变量；完整研究项目仍通过 CLI＋Skill 执行三个研究者确认点。

本版包括持久状态、证据依赖、预算与恢复、调查数据审计、OLS/WLS/Logit、来源定位、结果写作、复核与成果导出。GUI目前仅覆盖模型配置、连接和小任务；不是完整项目管理界面。模型兼容协议不等于科研能力验证，其他模型须各自通过能力契约与评估。

## 本版新增修复

修复中文及带引号目录的隔离执行，改进高精度小数与敏感标识的区分，明确加权拟合优度字段，阻断超预留费用的响应复用，并处理六类畸形付费响应。所有反例均由本机合成服务或合成数据构造，没有新增真实付费模型调用。

## 验证证据与范围

完整软件回归在 macOS、Python 3.12 下启用真实隔离：170项通过，0失败，0错误，0跳过。测试包含组件替身、合成本机协议和真实系统隔离，各自只证明相应范围。

正式安装包另在新的非 editable 环境安装并运行自动工程验收。精确安装包哈希、软件报告、逐组结果与自动工程观察哈希见同目录 `preview-a4-validation.json` 及 Release 附件。旧版120项记录是历史证据，不能替代本版结果。

当前实际验证系统为macOS。Linux隔离后端已有实现，但独立Linux集成仍未完成；本预览不宣称Linux已验收。Word/DOCX使用内部引文键，完整APA7、ICA或CSSCI格式、全文语义和逐页视觉核查仍需研究者处理。

## 正式放行仍缺少

- 独立人员按公开操作完成安装、授权、计划冻结、恢复、复现及终审。
- 至少100个真实来源与论断对的文献双专家核查。
- 固定模型30个独立保留任务各3次的科研盲测；既有两次接口调用不计入。
- 三个获授权真实项目的研究负责人和方法审阅者接受记录。
- 独立复现、Linux验证和真实使用成本等实测证据。

已有一项实际研究工作稿未完成真人终审，不计作通过的试点。原始调查数据、研究者本地文献、密钥和个人研究目录均不在软件发布资产中。后续修改后须重新绑定候选包与验收证据，不能沿用旧版本的通过记录。
