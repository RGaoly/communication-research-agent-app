## 反例与修复

- [首次 Linux 基线](https://github.com/RGaoly/communication-research-agent/actions/runs/40706892233)实际出现三项隔离自检失败，其余 167 项通过。保留失败，不通过跳过用例或取消隔离取得通过。现在使用经宿主确认可达的监听器作为网络正控，并封闭根及临时挂载的越界写入。Ubuntu 临时 CI 环境调整 user namespace 设置，不在用户机器或生产宿主上自动修改内核策略。
- 后续规格失败时，先前成功及零结果原来未随失败保留。现在逐模型原子登记成功、失败、中断与未运行状态，失败诊断包保留进度及哈希；部分结果不能被当作完整研究成果。
- 统计源码或依赖改变时，旧分析原来仍可被复用。现在将统计代码、Python 和依赖身份接入证据关系，相关结果和终审随变化失效。重新计算后审计与方案完全相同时可以复用相同范围的方案确认，但需要新成果终审。导出包同时核对实际统计源码身份，重写普通文件清单不能掩盖替换。
