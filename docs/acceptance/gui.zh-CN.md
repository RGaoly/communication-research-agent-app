# 图形界面使用说明

macOS 双击仓库中的 `启动模型配置.command`；已安装 wheel 后也可运行 `cra-gui`。页面自动打开；服务仅监听 127.0.0.1，默认选择空闲端口。关闭启动窗口或按 Ctrl+C 停止本机服务。

1. 选择 DeepSeek，或选择其他兼容端点并填写 HTTPS 地址与模型 ID。
2. 在页面填写 API Key；需要时展开地址、模型、输出上限和价格设置。
3. 点击“保存配置”。密钥只在页面内存，服务仅保存非敏感配置到当前进程内存。
4. 点击“测试连接”，执行一次最多 32 输出 token 的真实请求。
5. 在“研究小任务”填写不含行级调查数据的说明，点击“开始分析”。

当前运行授权总计最多 **两次生成调用和 5 美元**。界面会显示真实 token 用量、缓存命中/未命中、估算费用、预留与待核对状态。费用账本存于 `work/gui-session/gui-usage.sqlite`；刷新不会清空，重新启动同一目录也不会重新授予两次额度。不得通过新建目录规避授权。未知请求阻断自动重发，实际账单核对后另行决定后续授权。

DeepSeek 默认采用用户提供的价格：低谷缓存命中每百万 $0.003、未命中 $0.15、输出 $0.60；工作日北京时间 09:00–12:00 与 14:00–18:00 按两倍估算。预留费用始终按保守高峰上限。`reasoning_tokens` 属于输出 token 子集，不重复加收。接口价格、时间口径可能变化，估算不能替代账单。

默认 ID `deepseek-flash` 在核查当日官方说明映射至 DeepSeek-V4.1-Flash-1017，但它仍是服务端别名。程序记录真实返回的模型字段，不将其当作永远固定的模型版本。[官方接口说明](https://api-docs.deepseek.com/quick_start/pricing)，核查日期：2026-10-28。

“读取模型列表”只做用户点击触发的元数据请求；不是工具调用契约或科研能力测验。更换厂商、地址或模型后必须重新保存；界面会使旧配置失效，避免向页面未确认的端点发送密钥。

请求路径为：页面 → 本机服务 → 你保存的厂商 HTTPS 端点。没有第三方中转；厂商会收到本次任务说明。浏览器只访问本机接口，避免厂商 CORS 限制。不自动上传项目文件，没有任意文件读取入口。敏感内容检查是启发式检查，不能保证完全匿名。

服务要求精确本机 Host、同源 Origin 与随机会话标记，不开放 CORS；不跟随到其他域的凭据重定向。自定义端点必须解析到公网；对已授权官方 DeepSeek 域名兼容本机 DNS 代理的 198.18.0.0/15 映射，HTTPS 主机名和证书校验始终保留。

密钥不进入 localStorage、Cookie、项目文件或费用账本；服务不会记录请求正文和密钥。模型输出仅保留页面，账本只存结果哈希、模型、用量和费用。页面刷新清空密钥；“清除密钥”立即清空输入框。这个承诺不覆盖浏览器插件、操作系统进程内存、厂商服务器或同一系统账号的恶意访问。

本页是模型接入和一次小任务入口，不代替完整研究项目界面，也不能代签授权、计划冻结、成果终审或伦理声明。两次真实调用结果须与自动模拟、专家盲测、真实试点分开报告。
