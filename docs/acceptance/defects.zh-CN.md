# 本轮缺陷与复验记录

| 编号 | 发现与影响 | 实际改动 | 复验依据 |
|---|---|---|---|
| CRA-A01 / P0 | 代码审查发现：模型费用结算后、任务产物提交前崩溃，恢复可能再次请求相同付费内容。未声称真实厂商已经发生重复扣费 | 费用与结构化响应同一事务持久化；恢复匹配配置和请求哈希重放；任务产物提交时才消费响应 | `test_paid_reply_replayed_after_interrupted_task_without_new_request`、`test_paid_response_checkpoint_survives_reopen`、`response_checkpoint` 十次故障注入 |
| CRA-A02 / P1 | 已知金额的待核对费用可能同时计入已用和预留，导致重复占用预算 | 仅对未知金额的 reserved/uncertain 请求保留预留；待核对状态仍阻断新请求 | `test_known_but_uncertain_cost_is_not_reserved_twice` |
| CRA-A03 / P1 | 仅设置暂停标记不足以证明统计进程结束；异常退出路径缺少强制清理保障 | finally 清理统计进程组；SIGTERM 转为可保存检查点的取消；macOS worker 监测父进程存活，Linux 保留 die-with-parent | 对真实 worker 分别施加 pause、SIGTERM、父进程 SIGKILL；记录实际 PID、退出码及无运行遗留 |
| CRA-A04 / P1 | 研究不可行或材料未齐时，没有独立诊断包出口 | 新增 `cra export --diagnostic`，不要求捏造稿件或人工批准，不包含原始数据 | 从未批准项目执行公开 CLI 导出，核对 manifest 和 `research_completed=false` |
| CRA-A05 / P1 | 原发布检查依赖计数、源码哈希和试点声明，不能充分核实成果与复核来源 | 绑定 wheel、原始观察、实际包和外部可信 Ed25519 评审签名；操作人签署绑定全部自动观察；缺项拒绝放行 | 对缺证据、无签名、错误角色、错误哈希、篡改签名及原始观察变化进行负例检查；本轮 release_eligible 保持 false |
| CRA-A06 / P2 | 实际合成闭环中，“does not identify a causal effect”被关键词规则误判为因果断言 | 只豁免明确的窄范围否定短语；同句中额外肯定因果断言仍被拒绝 | `test_negative_causal_limitation_is_allowed_but_positive_clause_blocked`；这不是完整自然语言推断验证 |
| CRA-A07 / P1 | GUI 首次连接在发请求前被本机 DNS 代理的 198.18 映射拦截 | 仅对用户已授权的 DeepSeek 官方域名兼容该映射；其他自定义私网端点仍拒绝，TLS/域名/跨域凭据限制不变 | 真实 GUI 两次调用成功；专门测试官方 fake-IP、自定义 fake-IP 和官方回环地址三种情况 |
| CRA-A08 / P1 | 真实隔离执行在中文目录或包含引号的目录中失败；原测试仅覆盖英文路径 | Seatbelt 路径保留 Unicode 字面值，同时转义引号；不放宽文件或网络限制 | 修复前真实 worker 失败；修复后英文及中文带引号目录均通过隔离探针与实际数据审计 |
| CRA-A09 / P1 | 旧验证器把高精度小数误报为证件号；引擎的相反修正规则又可能漏掉紧跟句点的联系方式 | 仅排除数字小数上下文，保留正文标点后的检查 | 小数不误报、合成联系方式和证件哨兵仍阻断；不声称完全匿名 |
| CRA-A10 / P1 | WLS 的加权拟合优度误标为普通 OLS R² | 分开输出 weighted_r2、weighted_adjusted_r2 与 OLS/McFadden 字段 | 独立加权残差平方和与调整自由度公式对账，防止统计含义混淆 |
| CRA-A11 / P0 | 模拟服务返回超出预留的 usage 时，原实现仍接受并缓存响应 | 先事务提交真实返回的估算费用，转待核对状态，不缓存响应，停止后续调用 | 修复前反例失败；修复后仅观察到一次本机请求、费用保留且禁止重发；未声称发生真实超额计费 |
| CRA-A12 / P1 | 非对象响应、错误 usage 类型、巨大计数、空 choices 或未知结束原因可能抛出非预期异常或被接受 | 校验响应结构、有限费用、模型身份和结束状态；失败持久登记为费用待核对 | 六类本机协议反例均停止，原始正文不回显且不重发；真实科研能力仍需盲测 |
| CRA-A13 / P1 | Linux 实际 CI 三项隔离自检失败；关闭端口不能作为网络隔离的充分证据 | 使用宿主已确认可达的监听器作为正控；封闭根与临时挂载写入；隔离失败仍停止 | 首次失败运行保留；最新 Linux 180 项及真实隔离、安装包验收通过；测试不取消隔离、不跳过 |
| CRA-A14 / P1 | 多模型中后续规格失败时，之前成功及零结果未进入失败诊断账本 | 逐模型原子保存进度，绑定失败运行与诊断导出；部分结果保持未完成状态 | 真实 worker 合成反例保留第一项零结果、第二项失败和第三项未运行；全量复验见 readiness-a5.md |
| CRA-A15 / P0 | 改动统计代码或依赖后，旧分析可能仍被复用并报告完成 | 将代码、Python 和依赖身份绑定审计、分析与导出；使受影响结果和终审失效，历史证据保留 | 改动前真实 CLI 反例失败；修复后代码与依赖变更失效、相同方案重建及篡改成果包拒绝均通过 |
| CRA-A16 / P1 | 仅报一项测试通过且填写匹配源码哈希的汇总，会被错误认作充分的软件证据；真人与其他门槛仍会阻断正式发布 | 将原始 JUnit、冻结的全部用例身份和版本报告登记到验收包，并由独立操作人的观察签署覆盖；外部任意汇总不能替换 | 修复前一项声明反例失败；修复后 Linux/macOS 同一安装包各 191 项及完整自动工程组通过，见 readiness-a5-dev1.md；无真人签署 |
| CRA-A17 / P1 | 托管工作台本机隔离失败时，项目环境自检只呈现本机结果；即使远程 worker 健康，也没有显示独立检查结果 | 自检分别呈现当前执行位置与已配置 worker 状态；只调用健康接口，不改执行范围、不传项目材料；页面明确说明仍需单独选择远程及同意传输 | `test_environment_check_reports_configured_remote_worker_without_changing_project_scope`、失败路径配对测试及 `test_settings_button_shows_remote_health_when_current_local_isolation_fails`；实际云端 worker 检查先前通过，本次改动仍需 Streamlit 新部署后复验 |

严重性表示本项目的放行影响，不代表已发生真实科研、隐私或计费事故。上述代码级修复不消除方法专家、独立操作人和真实试点的欠缺。
