# v0.2 开发预览交付与验收记录

日期2026-10-28，用户时区Asia/Shanghai。代码版本0.2.0a1，分支`feat/autonomous-research-engine`，实现基线`ac89d62`。这是自主研究引擎的开发预览，不是已经完成真实科研质量验收的正式版本。

## 实际交付

新增可安装`cra`与`python -m cra_engine`入口、事务任务/证据/批准/预算存储、按依赖失效、恢复与暂停、可信隔离统计worker、文献与模型适配、规范计算声明、中英文稿件、两个逻辑审阅角色及有限修订、目标规则、复现和版本化导出、迁移预览/备份、发布门槛检查。

源码位于`src/cra_engine/`；研究者入口与数据契约见[使用说明](usage.zh-CN.md)，决策和边界见[架构](architecture.md)，33项P0逐项见[需求追踪](requirements.md)。`examples/run_engine_demo.py`准备160条模拟数据与离线材料，不自动创建人工批准。旧原始Skill与旧标准库脚本保留原文。

## 测试中修复的问题

- 敏感号码模式误拦部分统计小数：修正边界，保留实际敏感内容阻断。
- 代码本从数据库导出重排键导致输入哈希变化：改为复制源字节；独立复现测试验证。
- 中文DOCX在无CJK字体映射的渲染环境缺字：明确中文字体与QA字体配置，重新渲染并检查全部页面。
- 强制退出、结果未知和材料变化的恢复：保留已提交事务与历史版本，不盲目重发付费调用。

## 当前验收结论

软件层、数值层和模拟闭环已有可运行证据。**正式发布门槛未通过。** 对最终模拟项目执行release-check会返回release_eligible=false、真实试点数量0、成果终审未完成、项目为模拟等明确阻断项；这是正确行为。

软件测试不能确认理论原创性、问卷内容效度、真实数据真实性、文献语义支持、完整匿名、因果识别或论文录用。supported和人工核查均是本地声明，模型审阅不能认证它们。当前三个角色使用同一配置模型的分离上下文，不宣称是独立同行评审或已验证的多模型科研系统。

## 剩余发布事项

1. 至少三个获授权、脱敏真实项目，每项有研究负责人和方法审阅者终审、独立复现与证据检查。
2. 用真实模型、独立保留研究集验证研究质量、文献支持准确率与合理停止；没有使用用户密钥或付费API替代这一项。
3. 测量主动操作时间、恢复率与真实项目指标；≥40%时间节省等仍是目标，未声称已达到。
4. Linux bubblewrap实际集成验收；当前只有实现和契约，实际运行证据来自macOS。Windows未支持。
5. 完整APA7/中文期刊排版、作者—年份引用渲染、Word/PDF匿名元数据语义检查仍需人审/后续适配。官方基础规则和建议分级已实现。
6. 跨国等值性、多层/SEM、复杂抽样、信息实验、R/Stata、分角色不同模型、任意动态研究代码和长期多项目协作保留为后续能力，不能宣传为当前完整支持。

当前调度器顺序执行，满足不超过2的授权并发上限，但未实现并行调度。统计使用可信适配器，不运行任意模型生成代码；隔离不可用时停止，无不安全回退。小单元格抑制和模式检查不构成完整隐私证明。

## 审阅与发布

本次本地实现不自动推送远端，不发布包仓库、不投稿、不上传研究数据。源码、安装包、补丁和模拟工作稿可供审阅。之后的远端合并、真实模型费用和真实项目数据应按实际授权执行。
