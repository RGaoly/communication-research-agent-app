# 独立统计执行服务：部署与验收

状态：dev4 候选实现。已有本机真实 HTTP＋操作系统隔离测试；尚未接入用户服务器。生产部署、域名 TLS、实际服务器隔离与跨主机联调均需取得连接信息后执行。不要把本机测试写成云端验收通过。

## 使用动线

1. 管理员部署本文的独立执行服务，将真实 HTTPS 地址与服务凭证写入 Streamlit 的部署 Secrets。用户不用配置命令行或服务器凭证。
2. 工作台先验证服务身份、配方与依赖、真实隔离探针。失败时不上传统计数据、不降级成无隔离执行。
3. 用户上传获授权的调查数据，核查代码本、敏感字段、缺失与分析副本。
4. 在“模型与设置 → 统计执行位置”查看真实服务器地址，明确同意本项目分析副本转交该服务器，保存后重新确认项目授权。
5. 执行数据审计，准备理论与文献证据；冻结研究计划后执行统计，查看规格账本及结果。零结果和失败规格均保留。
6. 取消、恢复、复现和交付仍在原工作台完成。复现发起一项新的统计计算，不把服务器缓存伪称为重算。

原始上传文件、私人文献、LLM 密钥、研究者姓名与批准记录不发送到统计服务。服务接收经核查的分析 CSV、代码本和完整研究方案；代码本/方案可能包含题项和研究内容，属于此次明确授权范围。完整方案不得填写未授权的私人材料。模型服务仍只接收经检查的摘要和结果。

## 服务器与预算交接

需要：SSH 别名或地址、用户名/端口、本机可读取的连接配置或密钥文件路径、域名（如有），以及部署和持续运行预算的金额、币种和周期。不要在聊天发送私钥、密码或模型 Key。

取得这些信息前，不创建收费实例、不购买域名、不上传真实项目材料。先检查已有机器 OS、内核、CPU/内存、磁盘、服务端口与现有业务，再选择安装路径，不能覆盖其他服务。

建议部署在支持非特权用户命名空间与 bubblewrap 的独立 Linux VM；macOS 可用于本机工程测试。不能以开启 privileged 容器、关闭整机 AppArmor、放松全局安全配置的办法伪装隔离通过。无法满足探针就更换兼容环境或保留阻断。

## 发布物与版本

使用候选 wheel，前后端必须安装同一提交对应的包，采用 `deploy/worker/statistics-constraints.txt` 的统计依赖。Python **补丁版本也须一致**。当前开发机是 Python 3.12.14；先前云端报告是 3.12.16，部署时须重新读取实际报告并统一。版本不一致会在传输数据前停止。

管理员显式安装（路径按实际机器确认）：

```bash
/opt/cra-worker/.venv/bin/python -m pip install -c statistics-constraints.txt 'communication_research_agent_tools-CANDIDATE.whl[engine]'
```

安装指令示意中的 wheel 文件名需替换为实际构建产物。服务不自行安装或升级依赖。统计子进程只运行内置 `audit` 和 `analysis`，不接受 Python/Shell 字符串、客户端文件路径、插件或动态导入指令。

## 凭证与系统服务

为服务创建专用无登录用户 `cra-worker`；程序放 `/opt/cra-worker`，任务目录 `/var/lib/cra-worker` 由专用用户独占，凭证源文件 `/etc/cra-worker/token` 由管理员独占。用安全随机数生成至少32字符的专用凭证，只写受限文件，不在终端打印。

提供 `deploy/worker/cra-worker.service` 作为待安装模板。它包含：

- 非 root 运行，专用凭证由 root 所有、`cra-worker` 组只读（0640）的独立文件提供；服务端通过 `O_NOFOLLOW` 打开并校验文件身份、类型和权限，不在启动参数中放明文。目标阿里云镜像的 systemd 为 239，尚不支持 `LoadCredential`；更新的 systemd 可改用 credential directory。
- 启动前执行实际隔离自检；自检失败返回非零，不启动研究执行服务。
- 只读系统目录、私有临时目录、内存/CPU/进程数限制，以及停止时终止整个服务进程组。
- 单任务执行，最多4项排队/运行任务，每项最多300秒。最多128项未过期任务、100000条不含数据的历史索引；超额拒绝。

模板须在目标机器用 `systemd-analyze verify` 检查，并在 **实际 unit 限制下** 重做探针。独立终端的成功不能代表 unit 内成功。当前没有目标服务器，不能声称此模板已在生产验证。

## HTTPS

服务只监听 `127.0.0.1:8781`。使用 `deploy/worker/Caddyfile.example` 在域名443端口提供 TLS，部署前替换域名并执行 `caddy validate`。仅开放必要管理端口和HTTPS，不把8781开放到公网。

客户端验证公网 IP 和 TLS 域名，并直接连接已核验的 IP，拒绝重定向转发凭证。正式配置不接受内网/元数据地址、HTTP、任意端口、URL 用户密码。环回 HTTP 只用于自动化模拟测试，不提供网页开关。

配置语法参考 [Caddy request_body](https://caddyserver.com/docs/caddyfile/directives/request_body)、[全局超时](https://caddyserver.com/docs/caddyfile/options) 与 [systemd.exec](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html)。目标版本的配置检查结果优先，安装成功不等于隔离通过。

## Streamlit 接入

在 Streamlit 应用 Settings → Secrets 中填入 `deploy/worker/secrets.example.toml` 的实际值。真实凭证不得进入 Git、项目 brief、导出包或用户聊天。也支持管理员进程内的 `CRA_WORKER_URL` / `CRA_WORKER_TOKEN`，与研究者的模型密钥分离。

配置存在只表示可检查服务；旧项目不会自动扩大传输范围。每项目单独同意并保存范围后，当前授权失效，需要重新审阅。修改服务器或配方身份同样需要重新配置与批准。暂未配置服务或服务自检失败时，当前云端继续只提供材料与方案工作区。

## 任务、恢复与保留

接口：`GET /v1/health`、`POST /v1/jobs/{32位任务ID}`、`GET /v1/jobs/{ID}`、`DELETE /v1/jobs/{ID}`。全部要求服务身份认证。POST 只接收有限 JSON；认证在读取正文之前执行。输入校验、队列及落盘校验均不能授予新的研究权限。

工作台在 POST 前事务保存任务 ID 和请求摘要。响应丢失后查询相同 ID，不自动更换 ID 重跑；请求已提交但服务器查不到时交管理员核对。修改等待时长不会变成新任务。相同 ID 的不同输入被拒绝。

服务重启后，原排队/运行任务变为 `unknown`，不会自动重试。取消是尽力通知；已完成计算可以保留有效结果，失联时不能保证即时取消，已发出的任务仍受服务器300秒上限限制。工作台保存未确认状态，不假报完成。

成功结果绑定 CSV/代码本哈希、完整方案哈希、配方环境身份、统计结果摘要及任务号；失败分析保留成功/失败/未运行的规格进度。HMAC 证明响应来自配置的服务，**不能证明管理员不恶意、统计方法正确或形成独立科学复核**。

材料默认24小时到期，后台约每分钟清理终态/未知任务的输入、请求与结果，保留无材料索引防止重复执行。运行中的任务不清理。服务器磁盘和备份仍由管理员管理；该逻辑不承诺 SSD 安全擦除，也不替代数据授权。

## 部署后必测

1. 无凭证请求401，公网8781不可达，TLS证书与域名有效。
2. 在实际服务限制下，网络、越界写入、控制状态读取三个探针全部被拒绝。
3. Streamlit 读取到同一配方身份；没有每项目传输同意和测量核查时不能上传。
4. 用固定模拟 CSV 完成审计、冻结、OLS分析、复核与成果包，和本机参考实现对账。
5. 网络响应丢失后只查询同一任务；运行中取消；服务重启后未知状态不被伪报成功。
6. 篡改系数/哈希/服务身份时拒收；失败模型保留规格；重新计算产生新任务号且主要结果匹配。
7. 检查服务文件、日志、成果包：没有模型密钥、服务器凭证、私人原始材料或代签记录。
8. 确认实际资源计费在用户预算内；经此验证后才切换公开工作台。此前保持原部署可用。

这份清单是工程部署验收，不替代独立真人验收、文献双专家核查、90次真实模型盲测或三个获授权真实项目的验收。
