# 研究类型扩展接口 v1

`project.json.extension` 目前是声明式路由，不动态执行插件。接入者保留统一项目状态、六阶段门、脱敏副本、结果/图表/声明契约与人工审核；提供外部 recipe 标识、完整代码、环境、输入哈希、估计对象及限制。未知 recipe 明确显示“未自动重算”，不会悄悄获准为已复现。

| 接口值 | 应补的设计/测量/审计证据 | 建议下一步实现 |
|---|---|---|
| `survey` 媒体调查 | 抽样框/覆盖、权重、非应答、注意力、媒体接触与信任量表 | 复杂抽样与加权描述统计适配器 |
| `cross-national` 跨国民意 | 国家/语言/时间与抽样可比性、翻译、等值性、国家层样本量 | 多组 CFA/DIF、多层模型、跨组样本账本 |
| `information-experiment` 信息实验 | 分配单位与随机种子、刺激版本与时序、操作检查、流失、ITT/依从性 | 随机分配核对、预注册对齐、聚类/随机化推断 |
| `llm-sample` LLM 硅基样本 | 模型与版本/日期、提示、温度/种子、生成批次、重复依赖、参照真人样本 | 提示/版本哈希、批次依赖、真人验证与漂移监测 |

硅基响应不自动等于真实公众意见；API 重复调用不等于独立受访者，模型/提示变化会改变测量。禁止把模拟 persona 声称为实际招募样本。真人样本对照、外部效度和污染风险由人判断。MVP 不调用模型 API、不采集平台内容、不自动抓取媒体，也不做这四类研究的专用统计。

扩展代码应独立生成合法有限数值，未知字段/模型需在文档中明确。新增自动核查须有正常、损坏与边界数据测试，并说明检查覆盖与人工剩余项，不能只增加“已通过”字段。当前通用约束不适合负 R²/调整 R²等统计量时，先升级契约，不把不同指标塞进 `r2`。
