# 数据审计与统计分析

在授权的本地存储保留只读原始数据、来源/采集时间、清洗代码及版本。工具读取的 `data/input.csv` 是脱敏后的分析工作副本，`sample_n` 专指它的行数，不冒充最初招募人数。原始招募、排除、重复、注意力/时长/直线作答、清洗保留、各模型完整案例 N 和权重必须在 `protocol/data-audit.md` 对账。分国家/组别检查分布和缺失；小单元格与重识别风险需人工控制。

排除规则先说明理由，保留每步计数；不能依据结果方向筛样本。记录非概率/概率抽样、覆盖和非应答、设计权重/校准、实验随机化与处理时序。注意力题失败不是无条件剔除依据。不能把自动范围检查等同于数据质量认证。

`protocol/analysis.md` 至少列：每个 RQ 的因/自变量、理论控制项、样本范围、缺失策略、估计对象、模型、标准误、权重/聚类、主/次要分析、稳健性、图表、复现命令。缺失不默认填均值；多重插补、复杂抽样、聚类和多重检验要匹配设计。避免过度控制和将后处理变量当作常规控制；中介与调节区分验证性/探索性和识别前提。

内置 `analyze --x ... --y ...` 是功能示例：带截距的一元 OLS、完整案例、经典同方差 SE、N/b/intercept/se/t/R²，无 p/CI。`validate` 从 CSV 重算，核对 JSON、CSV 表格及 SVG 散点坐标。适合测试工具链，不替代完整实证分析。其他模型使用经核实的专门软件，登记 `recipe.id` 为外部标识，所有模型值须为有限数字；重跑、设计正确性与图形语义人工审查。

不要手工修统计输出。表图与文稿数字共同引用 `results.json`。每张表注明变量、参照组、SE 类型、缺失和样本、显著性标识；内置示例没有 p 值，不能添星号。图注在正文，提供轴标识与单位，复杂图提供绘图源。目标要求黑白时采用线型/点型区分；不把黑白设为全部期刊的硬规则。
