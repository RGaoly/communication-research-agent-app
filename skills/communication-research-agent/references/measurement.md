# 测量、问卷与跨国比较

`protocol/measurement.md` 记录构念层次、题项来源/使用权限、原文和译文、锚点、反向题、跳题、随机顺序、认知访谈/预测试、缺失选项、社会期许及共同方法风险。`data/codebook.json` 将论文变量映射到原始列、题目、编码、量尺、敏感性、派生规则和分析用途。ID 只用不可逆推出身份的本地研究标识。

先界定构念再选题项，不从可用列反推概念。多题量表先检查分布、反向编码、缺失及因子结构，再讨论内部一致性、聚合/区分效度；高 alpha 不等于单维度或有效。不要自动套用一个阈值宣布量表合格。

跨语言/跨国比较需记录翻译、独立核对与认知访谈证据，检查量尺和抽样框是否可比。配置/载荷/截距等值性按比较目的检验；均值比较需要相应可比性依据。部分等值性、反应风格或 DIF 的处理必须有透明理由，失败时缩小结论，不能将偏差解释为国家真实差异。

态度、对他人态度的推测、外部样本的态度及两者之差是不同对象。国家形象元知觉可作为一个场景，但同样方法可用于媒体信任、风险沟通、政治传播等，不预设题目。

工具只检查代码本列对应、数值有限/范围、类别枚举、声明敏感变量和重复 ID。题项含义、内容效度、跨文化等值性、量表许可与伦理均由人工判断；MVP 不执行 CFA/SEM。
